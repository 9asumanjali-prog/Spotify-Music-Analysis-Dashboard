# 🎵 Spotify Music Analytics Dashboard

## 📊 Spotify Music Analytics – Business Insights Dashboard

The **Spotify Music Analytics Dashboard** is an interactive **Power BI dashboard** designed to analyze music streaming data and uncover insights into **songs, artists, popularity, album types, release years, explicit content, and monthly trends**.

The dashboard transforms raw Spotify data into an engaging dark-themed visual experience, making it easier to understand music trends, identify popular artists and songs, and analyze changes in song popularity over time.

## 🎯 Project Objective

The main objective of this project is to analyze Spotify music data and create an interactive dashboard that helps users:

* Identify the most popular songs and artists
* Analyze song popularity trends
* Compare single and album releases
* Understand explicit vs. non-explicit content
* Analyze songs released across different years
* Track monthly popularity trends
* Identify months with the highest number of distinct songs
* Explore music data through interactive visualizations

## ✨ Key Dashboard Features

### 🎵 Song & Artist Analysis

Provides an interactive list of songs and their corresponding artists, allowing users to explore the music dataset.

### 📊 KPI Overview

The dashboard displays important metrics including:

| KPI                   |        Value |
| --------------------- | -----------: |
| 🎵 Distinct Songs     |          789 |
| 🎤 Artists            |          342 |
| ⏱️ Average Duration   | 3.28 minutes |
| 🔥 Average Popularity |        89.62 |

### 💿 Album Type Analysis

Analyzes the distribution of music based on album type, including:

* Singles
* Albums
* Other album categories

### 🔞 Explicit Content Analysis

Compares:

* Explicit songs
* Non-explicit songs

This helps understand the proportion of explicit content within the dataset.

### 📅 Songs by Year

Analyzes the number of songs across different release years and helps identify changes in music releases over time.

### 🎤 Popularity by Artist

Ranks artists based on their popularity and provides an easy way to compare leading artists.

### 🎶 Popularity by Songs

Highlights songs with high popularity scores and enables comparison between the most popular tracks.

### 📈 Average Popularity by Month

Displays monthly changes in average song popularity, helping identify periods with higher or lower popularity.

### 📊 Distinct Songs by Month

Shows the number of distinct songs associated with each month and helps identify monthly patterns in the dataset.
